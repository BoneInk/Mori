MIRROR DESIGN NOTE · 01

Mirror：安静的
Markdown 写作

Mirror 是一款面向 macOS 的原生 Markdown 编辑器。这次改造把注意力重新交还给内容本身。

设计原则

清晰的层级

使用细分隔线和留白组织区域，减少容器感。所有选中状态只使用 低饱和青绿。

内容优先

  • 工具栏只保留高频入口
  • 文件树与大纲使用统一行高
  • 编辑器与预览保持同等视觉权重

保留核心工作流

浏览、定位、编辑、预览仍在同一窗口完成。
区域主要任务
文件树浏览工作区与最近文件
大纲快速定位文档章节
主区编辑与实时预览

交互细节

侧栏可以分别关闭，三种视图模式可以即时切换。状态栏保留保存状态、编码、行列与字数。
